📊 Universal Data Cleaner (Python & Streamlit)
A robust, user-friendly tool to transform "messy" CSV datasets into analysis-ready Excel files. This project streamlines the data cleaning process for analysts, ensuring data integrity before performing SQL queries or visualization.

🚀 Features
Automated Cleaning: Instantly removes duplicate rows and standardizes text to proper case.

Missing Value Handling: Choose between dropping rows with null values or filling them with zeros.

Dynamic File Conversion: Upload any CSV file and export a cleaned version as an .xlsx file.

Interactive UI: Built with Streamlit for a seamless, browser-based user experience.

🛠️ Tech Stack
Language: Python 3.10+

Libraries: * Pandas: For data manipulation and deduplication.

Streamlit: For the web interface.

Openpyxl: To handle Excel file generation.
